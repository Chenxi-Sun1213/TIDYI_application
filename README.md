# TIDYI application

This directory is the clean handover package for the six formal RA analyses.
The original project remains at `/scratch/chenxi.sun/RA project` as historical
source material and is not required as the output destination of these masters.

## Current status

- The six master scripts, their required notebooks/helpers, lightweight inputs,
  and reference outputs have been assembled.
- The two AER H5AD inputs were copied to
  `/srv/mfs/hausserlab/data/AER2025_Juliane/` and verified by SHA-256.
- Mukin and TMS H5AD inputs remain in their existing `thesis_project` paths.
- Objective 3 now regenerates its five rate CSVs from those H5ADs by default;
  it also regenerates reference CVs using the original Mukin/TMS H5AD annotations
  and tissuewise cell counts. Bundled legacy rate/CV CSVs remain for explicit
  compatibility runs.
- Except for Objective 2, mouse gene-name mapping uses the shared frozen file
  `inputs/gene_mapping/mouse_symbol_to_ensembl.csv`; analysis code has no online
  mapping fallback. Its policy and source checksums are documented beside it.
- The 2026-10-06 mapping policy uses the replay3 archived MyGene cache alone,
  retaining unresolved genes without AER/BioMart supplementation.
- Objective 2 was restored on 2026-10-12 to the legacy local mart mapping and
  retains only genes covered by that table.

Read `RA_PROJECT_HANDOVER_GUIDE.md` before running anything.

## Directory map

```text
RA_project_handover/
├── README.md
├── RA_PROJECT_HANDOVER_GUIDE.md
├── handover_utils.py
├── inputs/                         # small, versioned analysis inputs
├── 01_rate_reproducibility/
├── 02_mouse_human_skin/
├── 03_death_proliferation/
├── 04_arigoni_cancer/
├── 05_aer_developmental/
└── 06_systems_biology/
```

Every objective directory uses the same output convention:

```text
master_*.py          # only formal entry point
outputs/             # generated by the next manual run
reference_outputs/   # pre-handover results for comparison; never overwritten
```

## Manual run order

Run one objective at a time:

```bash
python "/scratch/chenxi.sun/RA_project_handover/01_rate_reproducibility/master_rate_reproducibility.py"
python "/scratch/chenxi.sun/RA_project_handover/02_mouse_human_skin/master_mouse_human_skin.py"
python "/scratch/chenxi.sun/RA_project_handover/03_death_proliferation/master_death_proliferation_dominance.py"
python "/scratch/chenxi.sun/RA_project_handover/04_arigoni_cancer/master_arigoni_scidata_2024_validation.py"
python "/scratch/chenxi.sun/RA_project_handover/05_aer_developmental/master_aer_developmental_validation.py"
python "/scratch/chenxi.sun/RA_project_handover/06_systems_biology/master_systems_biology_model_fitting.py"
```

Objective 3 is now a full single-cell-to-rate-to-dominance run. Use
`--use-precomputed-rates` to run the downstream analysis with an existing
five-table rate set.
